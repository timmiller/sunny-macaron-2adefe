⚠ Compliant Language Standards — All Staff, All Stages

  • Never use the word cure in any patient-facing context
  • Never use the word fix in any patient-facing context
  • Never use the word reverse in any patient-facing context
  • Never use treat as a medical claim — e.g., "We treat arthritis" is strictly prohibited
  • Never use the word guarantee in any patient-facing context
  • Personal social media: if you identify as working for a regen medicine practice, your posts are legally attributable to the practice. No disease claims, no patient stories. When in doubt — do not post.
